# 3D-модели (Blender)

Все модели собираются скриптами на Python из **Blender 5.2** (скачан с blender.org), поэтому их можно
менять и пересобирать.

## ВАЗ-21214 «LADA 4x4» (Нива, 3 двери): детальная модель по фото

| Файл | Что это |
| --- | --- |
| `vaz_niva.blend` | готовая сцена Blender: машина, студийный свет, камера, выставленная как на фото |
| `vaz_niva.glb` | та же модель в glTF (для других программ и движков) |
| `blender/vaz_niva.py` | исходник модели |
| `previews/niva/` | рендеры с разных ракурсов, в том числе с ракурса фото (`photo.jpg`, `match.jpg`) |

Как сделана:
- **Габариты:** по заводским данным: 3740 × 1680 × 1640 мм, база 2200, свесы 705/835, колея 1430/1400,
  шины 185/75 R16.
- **Кузов:** профиль сбоку, сечение и вид сверху сняты с размерного чертежа ВАЗ-2121/21214. Кузов — одна
  оболочка, окна и колёсные арки прорезаны булевыми операциями, поэтому сквозь стёкла виден салон.
- **Детали:** как на фото (21214 конца 2010-х): чёрная решётка с круглыми фарами и эмблемой-ладьёй,
  поворотники над фарами (оранжевые снаружи), тонкий бампер с номером «4x4», чёрные расширители арок,
  пороги и зеркала, «жабры» на задних стойках, литые диски с пятью сдвоенными спицами, подвеска под днищем
  и салон.
- **Сверка с фото:** камера подобрана по 23 опорным точкам фотографии (средняя ошибка ≈3 px на кадре
  300×225). Модель рендерится с этого же ракурса для сравнения.

Пересборка и рендер:

```sh
blender -b --factory-startup --python models/blender/vaz_niva.py -- --export models            # .blend + .glb
blender -b --factory-startup --python models/blender/vaz_niva.py -- --render out --views photo,side,rear34,front,high34,nose
```

## Модели для карты «Долина» (low-poly)

58 моделей: машины (седан, хэтчбек, пикап, фургон, автобус, грузовик, танк, трактор, сгоревший седан),
деревья, камни и кусты, уличные объекты (фонари, ЛЭП, остановка, контейнеры, знаки, колодец и др.)
и мебель для зданий.

| Файл | Что это |
| --- | --- |
| `blender/fracture_models.py` | исходник всех моделей |
| `fracture_models.blend`, `fracture_models.glb` | все модели в одной сцене |
| `fracture_models.json` | геометрия в формате для игры (метры, перед модели смотрит в +Z) |
| `previews/*.jpg` | рендер каждой модели |

```sh
blender -b --factory-startup --python models/blender/fracture_models.py -- --render models/previews --export models
```

Ключи `--only sedan,bus` и `--cat vehicle|nature|prop|furniture` ограничивают набор.
